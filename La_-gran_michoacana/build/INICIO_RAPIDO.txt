# 🚀 INICIO RÁPIDO - La Gran Michoacana POS

## Para compilar tu próxima versión

```bash
cd C:\ruta\del\proyecto\La_-gran_michoacana
npm run build:win
```

**Resultado:** Se crearán 2 instaladores en `release/`
- `La-Gran-Michoacana-Setup-X.X.X-ia32.exe` (32 bits)
- `La-Gran-Michoacana-Setup-X.X.X-x64.exe` (64 bits)

---

## Para distribuir al cliente

1. **Copia estos 3 archivos en la MISMA carpeta:**
   - 📄 `install.bat` (desde `/build/`)
   - 📦 `La-Gran-Michoacana-Setup-X.X.X-ia32.exe` (desde `/release/`)
   - 📦 `La-Gran-Michoacana-Setup-X.X.X-x64.exe` (desde `/release/`)

2. **Cliente ejecuta:**
   - Doble clic en `install.bat`
   - Selecciona versión (32 o 64 bits)
   - ¡Listo!

---
